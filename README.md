# Hotel Reservation System

A Java-based application for managing hotel rooms, guests, reservations, and booking-related operations.

## Features
- Manage hotel room information
- Store guest details
- Create and manage reservations
- Organize reservation records
- Support booking-related payment processing, as implemented

## Technologies Used
- Java
- Object-Oriented Programming (OOP)

## Project Structure
- `Guest.java` — Guest-related information
- `Hotel.java` — Hotel operations
- `Main.java` — Application entry point
- `PaymentProcessor.java` — Payment-processing logic
- `Reservation.java` — Reservation information
- `Room.java` — Room information

## How to Run
1. Install the Java Development Kit (JDK).
2. Open Command Prompt in the project folder.
3. Compile the Java source files:
   ```bash
   javac *.java
   ```
4. Run the application:
   ```bash
   java Main
   ```
